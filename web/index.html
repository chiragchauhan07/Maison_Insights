    CONNECTION SETTINGS

    Connect Apify

    1. Create or copy an Apify API token from your Apify account.
    2. In this project's .env file, set APIFY_TOKEN=your_token.
    3. Save the file, restart the app, then check the status again.

    Keep your token private. This app does not send the token to the browser.
    RESEARCH METHOD

    How this analysis works

    Collect public Trustpilot reviews, remove duplicates, validate review text, score title and text with VADER, then export the findings.

    • Star ratings stay numeric and conflicts with sentiment are flagged.
    • Reviewer names and profile links are not stored.
    • Unverified company domains are identified in the brand selector.

    Trustpilot is the only review source in this version.
